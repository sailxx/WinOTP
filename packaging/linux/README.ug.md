# Linux قۇرۇش ۋە تەستىقلاش

نىشان x86_64 Linux ، دەسلەپتە ئۇبۇنتۇ 24.04 ۋە Fedora بىلەن. NET 10 يەرلىك بېقىنىشچانلىقى. ئالدى تەرىپى Avalonia; Windows WinUI ئىلتىماسى ئۆزگەرمەيدۇ. Linux ئوخشاش ئىخچام ئورۇنلاشتۇرۇش ، سىئەن تەلەپپۇزى ۋە سىستېما تەلەپپۇزىغا يېنىك دەرىجىدە قاراڭغۇ رەڭ ئىشلىتىلگەن (ئىشلەتكىلى بولمايدىغان ۋاقىتتا نېيترال چېكىنىش): Windows Mica Alt ۋە Segoe UI ئۆزگەرگۈچى مىقدارنى ئېلىپ يۈرۈشكە ئەپلىك ئەمەس. Inter باغلانغان; ھېچقانداق Microsoft خەت نۇسخىسى قايتا تەقسىملەنمەيدۇ.

Linux ئاساسلىق مەخپىي نومۇرى AES -256- GCM ۋە PBKDF2 - SHA256 (600،000 تەكرارلاش) بىلەن ئامبارنى مەخپىيلەشتۈردى. ئۇ دەسلەپتە تەلەپ قىلىنىدۇ ، ئەسلىگە كەلتۈرگىلى بولمايدۇ. سانلىق مەلۇمات: `$XDG_DATA_HOME/WinOTP` ياكى `~/.local/share/WinOTP`. Vault مۇندەرىجىسى 0700 بولۇپ ، يېڭىدىن قۇرۇلغان ئامبار ھۆججىتى 0600. يازمىلار ئاتوم ، يازغۇچى قۇلۇپلانغان ۋە كونا تۈزىتىلگەن نەشرىنى رەت قىلىدۇ. مايىللىقتا ھېچقانداق مەخپىيەتلىك ساقلانمايدۇ. بىر ئامبار 500 گە يېقىن ھېسابات ۋە 14 MiB يۈرۈشلۈك سانلىق مەلۇماتنى قوللايدۇ (شۇڭا ئۇنىڭ Base64 زاپاسلاش 20 MiB ئىمپورت چېكىگە ماس كېلىدۇ). ھەددىدىن زىيادە تېجەش ئالماشتۇرۇشتىن بۇرۇن رەت قىلىنىدۇ. Windows DPAPI ھۆججىتىنى Linux غا ھەرگىز كۆچۈرمەڭ: پارول مەخپىيلەشتۈرۈلگەن ئېكسپورت قىلىڭ `.winotp` Windows نى زاپاسلاڭ ۋە ئۇنى Linux غا ئەكىرىڭ. ئەسلىگە كەلتۈرۈش دەلىللەنمىگۈچە مەنبەنى ساقلاڭ.

## يەرلىك تەرەققىيات

```sh
cd /path/to/WinOTP
dotnet run --project tests/Portable/Portable.csproj -c Release
dotnet run --project src/WinOTP.Linux/WinOTP.Linux.csproj -c Release
```

پەقەت ئاممىۋى RFC كىنىشكىسىنى ئىشلىتىپ ئايرىم كۆرۈش ئۈچۈن:

```sh
cd /path/to/WinOTP
dotnet run --project src/WinOTP.Linux/WinOTP.Linux.csproj -c Release -- --preview --screenshot "$PWD/assets/screenshots/linux-native.png"
```

## بوغچا

`.github/workflows/linux.yml` ئورالمىغا تايىنىشچانلىقىنى ئورنىتىدۇ ، مىخلانغان appimagetool ھەزىملىكىنى دەلىللەيدۇ ، deb / rpm / AppImage قۇرىدۇ ، Xvfb نىڭ ئاستىدا قەرزنى ئورنىتىدۇ ۋە باشلايدۇ ، AppImage نى FUSE ئىشلەتمەي باشلايدۇ ھەمدە ئورالمىلار ۋە ئېكران كۆرۈنۈشلىرىنى يۈكلەيدۇ. `linux-packages`. ئۇ PR لاردا ئىجرا بولىدۇ ، قولدا ئىجرا قىلغىلى بولىدۇ ئۇ ئېلان قىلمايدۇ. `packaging/linux/build.sh` يەنە x86_64 Linux مۇلازىمېتىرى بىلەن يەرلىكتە ئىجرا بولىدۇ. NET 10 ، fpm 1.16.0 ، rpm ۋە squashfs- قوراللار; تەمىنلەش `APPIMAGETOOL` دەلىللەنگەن 1.9.1 x86_64 ئىجرا قىلىنىدىغانلىقىنى كۆرسىتىپ بېرىدۇ. ھاسىل قىلىنغان بارلىق مەزمۇنلار ئاستىدا قالىدۇ `artifacts/linux`.

بەلگە خىزمەت ئېقىمى Linux ۋە Windows قۇرۇشنى ساقلايدۇ ، ئاندىن a تەييارلايدۇ **لايىھە** قاچىلاش پروگراممىسى ۋە ئۈچ Linux بولىقى بىلەن قويۇپ بېرىڭ. GitHub ئېلان قىلىنغان مۈلۈك ئۈچۈن SHA -256 ھەزىم قىلىشنى كۆرسىتىدۇ. ھەقىقىي Linux ئېكران كۆرۈنۈشلىرىنى تەكشۈرۈپ ، ئېلان قىلىنىشتىن بۇرۇن Vlad نىڭ تەستىقىنى ئېلىڭ. بەلگە قۇرۇش ياكى ئۆزگەرتىش ئىتتىرىش يەرلىك تەييارلىقنىڭ بىر قىسمى ئەمەس.

## قوبۇل قىلىش يەنىلا تەلەپ قىلىنىدۇ

ئۇبۇنتۇ ۋە Fedora دىكى rpm نى قاچىلاش / ئۆچۈرۈش / يېڭىلاش. ھەر ئىككىسىدە AppImage نى سىناق قىلىڭ (FUSE ياكى `--appimage-extract-and-run`). ئەمەلىي X11 / Wayland ئۈستەل يۈزى ، كۆلەملەشتۈرۈش ، چاپلاش تاختىسىنىڭ ۋاقتى ، ھۆججەت تاللىغۇچ ، QR ئىمپورت قىلىش ، مەخپىي نومۇر قۇلۇپلاش ، Windows زاپاسلاشنى ئەسلىگە كەلتۈرۈش ۋە HOTP نىڭ داۋاملىشىشىنى تەكشۈرۈپ بېقىڭ. RPM ئورنىتىش ۋە ئۈستەل يۈزى كومپوزىتور ھەرىكىتىنى ئۇبۇنتۇ CI خىزمىتى ئۆز ئىچىگە ئالمايدۇ. تېخى Linux تەخسە بىرلەشتۈرۈش ياكى چاپلاش تاختىسى-رەسىم QR ئىمپورت قىلىنمىدى. ھۆججەت QR ئەكىرىش ۋە URI ئەكىرىشكە بولىدۇ.

`assets/screenshots/linux-ui-preview.png` بۇ Windows ئالدىدىكى Avalonia ئالدى يۈزىنىڭ ھەقىقىي تەسۋىرى بولۇپ ، Linux ئىجرا ۋاقتىنىڭ سىنىقىنىڭ ئىسپاتى ئەمەس. بۇ ئۆزگەرتىش ئارقىلىق ھېچقانداق ئورالما ئېلان قىلىنمىدى.
